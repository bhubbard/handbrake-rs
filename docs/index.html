handbrake-rs — Memory-Safe Video Transcoding & Adaptive Bitrate Engine in Rust

handbrake-rs is a pure Rust re-architecture of the HandBrake video transcoding pipeline built for headless servers, CLI automation, and media workflows. It orchestrates hardware-accelerated AV1/HEVC/H.264 encoding, deinterlacing filters, chapter markers, and multi-track audio passthrough without C/C++ buffer vulnerabilities.

Rust SDK & CLI Installation

Cargo CLI Installation
# Install standalone HandBrakeCLI binary
cargo install handbrake-rs

# Transcode video using official preset
HandBrakeCLI -i input.mov -o output.mp4 -Z "Fast 1080p30"

# Discord 1080p preset with custom crop
HandBrakeCLI -i gameplay.mkv -o discord.mp4 \
  -Z "Discord Nitro 1080p" --crop 0:0:140:140
Rust Programmatic API
use handbrake_rs::{TranscodeEngine, TranscodeJob, Preset};
use std::path::PathBuf;

fn main() -> anyhow::Result<()> {
    let preset = Preset::find("Fast 1080p30")?;
    let job = TranscodeJob::from_preset(
        PathBuf::from("raw.mkv"),
        PathBuf::from("dist.mp4"),
        &preset,
    );

    TranscodeEngine::run(&job, |prog| {
        println!("{:.1}% | {:.1} fps | ETA: {}s", 
            prog.percent, prog.fps, prog.eta_seconds);
    })?;
    Ok(())
}
